# Installation Instructions

## For Users

Use `tar -xvzf Chess_V1.0.tar.gz`, then `cd Chess_V1.0`. \
\
To run the application, use `./bin/anteater_chess`

## For Source Code

First, use `tar -xvzf Chess_V1.0_src.tar.gz`, then `cd Chess_V1.0_src`, then `make` \
\
To run the application, use `./bin/anteater_chess`
